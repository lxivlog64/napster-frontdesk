# 3-minute demo video script (target 2:50)

| Time | Screen | Voice-over |
| --- | --- | --- |
| 0:00–0:15 | Title card, then a phone ringing out | "Small clinics miss one call in three. Every missed call is a lost booking." |
| 0:15–0:30 | Dashboard + avatar side by side | "This is Front Desk: one Napster Omniagent, with a face, a voice and a memory, on the web and on the phone." |
| 0:30–1:15 | Web: type phone, Start video call. Ask "Can I get physio Tuesday morning?" Agent checks, offers 3 slots, repeats details, waits for "yes", reads ref BK-…; row flashes on dashboard | "She checks real availability, confirms out loud before booking, and the booking appears live." |
| 1:15–1:50 | Phone call to the Twilio number (screen-record phone + dashboard). Agent greets caller by name and mentions Tuesday booking. Caller: "Move it to Wednesday at 10." Row updates, channel = phone | "Same agent on the phone. Napster passes the caller ID to our tools, so she knows who's calling before they say a word." |
| 1:50–2:15 | New web session with same phone: avatar greets by name and recalls "prefers mornings". Ask about cancellation policy (FAQ) | "Memory follows the customer across channels: Napster memory by external client ID, plus our own booking history." |
| 2:15–2:40 | Code: TOOL_DEFS prompts, setup-agent.js channels, `npm test` passing | "Five Napster tools with confirm-first prompts, VoIP tuned for phone audio, explicit HTTP tools behind a secret, no API key in the browser." |
| 2:40–2:50 | Outro card: repo + demo URL | "Front Desk: never miss a booking again." |

Recording notes: keep live sessions short (credits ~ $6 ≈ 100 min total). Rehearse once, record each segment once.
Pre-seed one returning customer by booking via the web first.
